# Changelog

All notable changes to `tupa-lints` will be documented in this file.

## [0.9.5] - 2026-05-16

### Added

- Initial release with lint constants:
  - `PIPELINE_UNUSED_METRIC` — warn when produced metric unused
  - `PIPELINE_TOO_LARGE` — warn when pipeline exceeds 20 steps
  - `CONSTRAINT_LITERAL` — warn when constraint uses literal
